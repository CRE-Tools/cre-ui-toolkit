## Description

Story files (`.stories.tsx`) currently live inside `packages/ui-kit/src/`. This causes lint errors in the editor because `packages/ui-kit` has no `@storybook/react-vite` devDependency — the TypeScript context for that package has no knowledge of `Meta`, `StoryObj`, etc. Stories are a documentation/consumer concern, not a library concern.

Move all story files to `apps/storybook/src/stories/`, organized by DS category. Update the storybook `main.ts` glob accordingly. After this task, `packages/ui-kit` contains zero storybook-specific code.

**Ordering note:** This task can run before or after TASK-003 (folder rename). Source paths differ — check the note in Relevant Data.

### Import pattern in story files after move
Component imports change from relative (`../Button`) to package imports (`@cre/ui-kit`) if they aren't already. Check each file.

```ts
// Before (relative, from inside packages/ui-kit)
import { Button } from './Button'
// or
import { Button } from '../Button'

// After (from apps/storybook, import from the package)
import { Button } from '@cre/ui-kit'
```

PendingReview import stays as-is (already set by TASK-002):
```ts

```
